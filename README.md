# ALPHA Institute - Student Management Website 


ALPHA Institute is developing a Student Management Website to manage student information in an easy and organized way.

This project is created as part of Git & GitHub Team Collaboration Workflow assignment. Each developer works on a separate feature branch and merges their work into the main branch using Pull Requests.

## Features
- Student Profile Page - Student Name, Registration Number, Course Name, Email Address and Introduction
- Student Dashboard - My Profile, My Courses and My Assignments
- Clean and Responsive Design

## Technologies Used
- HTML, CSS, JavaScript, Git & GitHub

## How to Run
1. Clone the repository
2. Open student.html in browser for Profile
3. Open dashboard.html in browser for Dashboard
